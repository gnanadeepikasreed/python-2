
# Progressive Electricity Billing

## Description
This project calculates electricity bills based on electricity consumption and progressive billing slabs.

## Features
- Accepts electricity consumption.
- Calculates slab-wise charges.
- Adds applicable fixed charges.
- Calculates the final electricity bill.
- Displays billing details.

## Concepts Used
Variables, operators, conditional statements, loops, and lists.

## Language
Python 3

## How to Run
python electricity_billing.py
